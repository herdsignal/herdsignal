# HerdSignal 현재 상태

문서 갱신일: 2026-08-03
기준 판정일: 2026-08-02
판정: `STATE_OBSERVATION_MVP_READY` / `NO_ADOPTABLE_ACTION_CANDIDATE`

이 문서가 제품과 연구의 현재 진입점이다. 수치가 다른 과거 문서와 충돌하면
기계 판독 원장 `data/herd/research_decision_v5.json`과 이 문서를 우선한다.

## 지금 사용할 수 있는 것

- `HERD_STATE_S1`: SPY와 개별 종목의 Flee–Rush 상태 관찰
- `HERD_TRANSITION_S1`: 주간 상태 변화 확인
- 대시보드 검색, 보유·관심 종목, 가격·HERD 이력
- 기업 정보와 개인 판단 기록
- 종목별 장기 운용 검토: 객관 근거, 개인 운용 조건, 실제 보유 비중, 독립 veto
- 51종목 범위의 SEC 접수시각 기준 매출·마진·영업현금흐름·부채 원시 사실
- 최근 550일 안의 SEC 원문 검수 경영진 가이던스 범위(지원 종목만)
- 명시적으로 저장한 판단의 해시 원장과 1·3·6개월 가격 경로
- 가격·Daily D1·State S1의 기준일과 수집 상태 확인

기본 행동은 `HOLD`, 운영 행동 비율은 `0%`다. State S1은 시장 상태이지
매수·익절 방향 예측이 아니다.

장기 운용 검토도 현재는 추천 모델이 아니다. 기업 체력은 지원 종목의 원시
SEC PIT 사실만 `PARTIAL`로 표시하며 기존 기업 상태 방향·veto 가설은 OOS
탈락으로 행동에 사용하지 않는다. 기대·가격 영역도 지원 종목의 최신 SEC
가이던스 원문 수치만 `PARTIAL`로 표시한다. 이는 상향·유지·하향 판정이나
컨센서스 surprise, 밸류 판단이 아니다. 원문이 없거나 오래되면 `NO_VIEW`다.
독립 시장·섹터와 정보 변화가 `NO_VIEW`임을 숨기지 않고,
데이터 gate가 닫히거나 방향 증거가 없으면 `INSUFFICIENT_DATA` 또는
`OBSERVE·0%`만 반환한다. 기록 API는 조회와 분리되어 사용자가 저장한
시점에만 새 행을 추가한다.

저장 판단의 1·3·6개월 결과는 고정 달력 목표일 뒤 7일 안의 첫 종가로
계산한다. 목표일 미도래는 `PENDING`, 목표일이 지났지만 가격이 없으면
`UNAVAILABLE`로 구분한다. 이는 저장 시점 이후 가격 경로이지 행동 적중률이나
매수·익절 성공 판정이 아니다.

섹터 ETF 참조와 시장 대비 상대강도는 State S1 내부 계산 자료다. 이를
독립 시장·섹터 판단으로 다시 세지 않으며, HERD 관찰 출처가 시장 영역으로
유입되면 Evidence gate가 차단한다. 별도 채택 소스가 생기기 전 시장·섹터
영역은 `NO_VIEW`다.

## 행동 모델 상태

- 전체 잠금·탈락 실험: 11개
- 최근 승격 심사 라운드: 6개
- 채택 가능한 후보: 0개
- 독립 OOS 방향 증거: 0개
- Blind holdout 접근: 0회
- 생존자 편향 안전성: `false`
- 운영 매수·익절 권한: 없음

런타임은 `model_evidence_admission_v1.json`뿐 아니라 그 원장이 참조하는 모든
OOS 결과의 SHA-256도 확인한다. 현재 추가매수·재진입 방향 증거와 기업 veto
증거가 모두 0개이므로 기업 veto 전향 시험 자체가 `BLOCKED_PREREQUISITES`다.
`OBSERVE` 기록을 ‘veto가 막은 매수’로 세지 않는다.

레거시 v4·v6.1은 비교와 실패 원인 분석에만 사용한다. 같은 OOS 표본에서
탈락 임계값을 조정하거나 탈락 변수를 다시 조합하지 않는다.

## 현재 연구 경계

SEC 8-K 훼손 사건의 ticker–CIK 원문 판정 110건이 남아 있다. 이 작업은
기업 훼손 시 추가매수를 막는 보조 veto 데이터 품질을 높이지만, 익절 방향
증거를 직접 만들지는 않는다. 해당 veto 연구를 재개하기 전까지 보류할 수
있으며 행동 모델의 최우선 작업으로 해석하지 않는다.

새 행동 연구를 바로 추가하지 않는다. 먼저 11개 실패를 목표 타당성, 경제
정보군 중복, 정책 기회비용, 신규 정보 가용성으로 합성 감사한다. 감사 뒤에도
새 정보가 남는 경우에만 다음 조건을 갖춘 단일 가설 하나를 허용한다.

1. 기존 실패 변수와 중복되지 않는 경제적 이유
2. 결과 확인 전에 고정한 공식과 관측시점
3. 새로운 독립 또는 prospective OOS 표본
4. 동일 조건 HOLD와 비용 차감 후 최종자산 비교
5. 실패 시 같은 표본에서 임계값 재조정 금지

## 새 단일 가설

`RUSH_WITH_NEGATIVE_EARNINGS_ANNOUNCEMENT_REACTION`을 2026-08-02에 결과
확인 전 고정했다. SEC 실적 공시 뒤 3거래일의 종목–섹터 잔차 반응이
-5% 이하이고 최근 주간 상태가 Rush일 때만 5% 익절 연구 후보로 기록한다.

기존 439종목과 겹치지 않는 54종목으로 동일 공식을 빠르게 반증했다. 완결
사건은 22건·16종목·6개 연도였고 경제성 지표는 기준을 넘었지만, 사전 고정한
최소 40건·20종목에 미달했다. 이어서 편출 종목 21개를 별도 표본으로
검증했지만 15건·9종목에 그쳤고, HOLD 대비 순최종자산 중앙값도
-10.66%p였다. 따라서 이 가설은 `INDEPENDENT_HISTORICAL_OOS_FAILED`로
종료하며 정식 전향 확인도 차단한다.

SEC 원문 사건 수집만 append-only로 계속한다. 이를 방향 증거로 해석하거나
126거래일 결과를 열지 않는다. 운영 권한은 계속 0개이며 자세한 계약은
`HERD_ACTION_HYPOTHESIS_V1.md`를 따른다.

## 개발 순서

1. State S1 관찰 제품을 안정적으로 유지한다.
2. 생성형 AI는 출처가 있는 사실을 관점별로 정리하는 연구 프로토타입으로만
   추가한다. 행동 비율이나 방향 권한을 부여하지 않는다.
3. 편출 종목 V2 21개의 SEC 실적 사건 2,070건과 독립 OOS 실패를 고정했다.
4. 실패한 실적 반응 임계값을 같은 표본에서 조정하거나 V1과 합치지 않는다.
5. 전체 11개 실패의 목표·중복·기회비용·누락 정보 감사를 먼저 완료한다.
6. 감사에서 독립 정보가 확인될 때만 단일 가설 하나를 결과 전에 고정한다.
7. 새 가설이 독립 OOS를 통과한 경우에만 전향 확인과 5% 정책 검증으로 이동한다.

## 확인 명령

```bash
./scripts/audit-current-state.sh
./scripts/verify.sh
```

누적 연구 이력은 `HERD_RESEARCH_STATUS.md`, 재현 방법은
`HERD_REPRODUCIBLE_RESEARCH.md`에 보존한다.

AI 프로토타입의 입력·출력 경계는
`HERD_AI_EVIDENCE_REVIEW.md`에 고정했다. 기본 비활성화이며 모델 연구
증거와 운영 행동에 연결하지 않는다.
