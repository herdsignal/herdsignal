# HerdSignal 제품 범위

상태: `LOCKED_PERSONAL_OBSERVATION_MVP`  
최신화: 2026-07-28

## 사용자

이미 장기 보유할 미국 주식을 직접 고른 개인 투자자다. 정기적인 신규 자금
유입이 적어 보유 종목의 상태 변화와 자신의 판단을 차분히 기록하고
복기하려는 사용자를 우선한다.

HerdSignal은 좋은 기업을 대신 고르거나 단기 가격을 예측하지 않는다.

## 핵심 작업

사용자가 반복해야 할 흐름은 하나다.

```text
대시보드
  → SPY 또는 검색 종목의 HERD 상태 확인
  → 보유·관심 종목의 의미 있는 변화 확인
  → 종목 상세에서 가격·HERD 이력과 근거 확인
  → 자신의 판단 기록
  → 이후 결과 복기
```

## 화면 권한

### 주요 화면

- `대시보드`: 검색, SPY·선택 종목 HERD, 보유 현황
- `관찰`: 관심 종목과 확인할 상태 변화
- `종목 상세`: 현재 상태, 시간 흐름, 근거, 판단 기록

### 보조 화면

- 자산 히스토리와 거래 원장
- 판단 기록
- HERD 연구실
- 설정

연구실은 모델 검증 상태를 확인하는 내부 화면이다. 사용자의 일상 관찰
동선보다 앞에 노출하지 않는다.

## 현재 제공 범위

- `HERD State S1` 상태 관찰
- SPY와 지원 종목의 Flee–Rush 위치 확인
- 포트폴리오·관심 종목 관리
- HERD 변화와 가격 이력 확인
- 사용자 판단 기록
- 로컬 가격·State S1 갱신 상태 확인

연구용으로는 State S1의 기존 근거만 관점별로 정리하는 AI 프로토타입을
둘 수 있다. 이 기능은 새 사실, 방향 예측, 행동 비율을 만들 권한이 없다.

## 제공하지 않는 범위

- 확정 매수·매도 추천
- 자동 주문과 자동 비중 결정
- 종목 추천
- 실시간 분봉·뉴스 터미널
- 국내 주식
- 증권사 자동 연동
- 생성형 AI 투자 조언
- 검증 전 행동 비율

이 항목들은 화면의 빈자리를 채우기 위해 추가하지 않는다. 별도 제품
판단과 검증 기준을 통과한 경우에만 범위를 변경한다.

## 표현 계약

- HERD는 시장 상태이며 높은 값이 자동 매도, 낮은 값이 자동 매수라는
  문구를 사용하지 않는다.
- 화면에는 관찰값 기준일과 데이터 최신성을 함께 표시한다.
- 검증되지 않은 연구 결과를 운영 신호처럼 강조하지 않는다.
- 기본 행동은 `HOLD`, 운영 행동 비율은 `0%`다.
- 개인 자산 금액은 사용자가 명시적으로 연 경우에만 표시한다.

## 완료 기준

- 처음 사용하는 사람이 10초 안에 종목을 검색하고 현재 HERD를 확인한다.
- 사용자가 가격 기준일과 State S1 기준일의 차이를 화면에서 구분한다.
- 보유·관심 종목의 변화가 없으면 억지로 알림을 만들지 않는다.
- 종목 상세에서 현재 상태, 과거 흐름, 근거, 자신의 판단을 찾을 수 있다.
- 모델 승격 전에는 어떠한 화면도 매수·익절 비율을 권고하지 않는다.
- AI 요약은 입력 근거 ID 밖의 주장을 만들면 전체 결과를 폐기한다.

기계 판독 기준은
`data/herd/product_scope_contract_v1.json`을 사용한다. 모델의 정량 채택
기준은 [HERD_ADOPTION_POLICY.md](HERD_ADOPTION_POLICY.md)가 담당하며 이
문서는 그 기준을 완화하지 않는다.
